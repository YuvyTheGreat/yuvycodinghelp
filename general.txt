Lightening up a rust compilation

CARGO_BUILD_JOBS=1 \
CARGO_PROFILE_RELEASE_LTO=false \
CARGO_PROFILE_RELEASE_CODEGEN_UNITS=16 \
CARGO_PROFILE_RELEASE_DEBUG=0 \
cargo build --release

  - LTO is something random that increases usage
  - Codegen units split work into smaller chunks
  - Debug removed

Jobs

A job is any process that is managed by the CURRENT shell session. "jobs" shows all jobs.

To pause a process that is running do ctrl z.
To move a process to the background use bg %1 (or your job id).
Add an & to any command to run it in the background.

To kill a job do kill -9 1 (or job id)

To bring it back do fg 1 (or job id)

To find a process use pgrep -fl

Tmux Guide

To start a new tmux window, just type tmux.
To deattach the current winodw tmux detach-session
To kill a session do tmux kill-session 
To attach a specific session do tmux attach -t 0 (or the number.
To turn mouse on do tmux set -g mouse on

According to copilot: tmux new -s mysession 

Split Screen 

tmux split-window -h or -v
tmux select-pane -L -R -U -D for navigating between panes
tmux select-pane -t 0 for selecting a specific pane

General

- For nslookup install dnsutils
- For folder/file size calculations use du -h
  - Du returns file sizes in bytes
  - 1 kilobyte returns 1K
  - 1 megabyte returns 1M
  - 1 gigabyte probably returns 1B

- For sorting through output use the sort command, like top | sort -n or something
- Head or tail with -n 5 parameter for first 5 or last 5
- ${string:start:length} for string slicing, for example ${"awef":1:5}
- For arrays you can do like arr[0]

- To force angband to use the terminal to run do: /usr/games/angband -mgcu

- For ssh if you want to specify a key to use do ssh -i "path/to/key"
